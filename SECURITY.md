# Security Policy

## Reporting A Vulnerability

Please do not open a public GitHub issue for security-sensitive reports.

Email vulnerability details to:

```text
dima@inovector.com
```

Include as much of the following as you can:

- Affected Mixpost version, commit, or package constraint.
- Laravel, PHP, database, queue, and hosting details that are relevant to the issue.
- A clear reproduction path or proof of concept.
- Expected impact, affected routes or commands, and any required privileges.
- Whether the issue affects Mixpost Lite, Mixpost Pro/Enterprise, or an unknown edition.

## Disclosure

Give the maintainers reasonable time to validate and fix the issue before public disclosure. If you are unsure whether something is security-sensitive, report it by email first.

## Supported Versions

Security fixes are prioritized for the latest released Mixpost Lite version and the currently supported commercial editions.
